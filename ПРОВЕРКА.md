# Как проверить самому

Команды для PowerShell, запускать из папки проекта:

```powershell
cd C:\Users\hedi\Скрипты\Тестовое_Руссмаркет
```

## 1. Тесты, без модели

```powershell
python -m unittest test_summary -v
```

Должно быть `Ran 22 tests ... OK`. Если что-то упало, в выводе будет имя теста и что именно не совпало.

## 2. Сводка на правилах

```powershell
python summary.py data/cases_2026-11-02.json
```

Сводка печатается прямо в консоль. Проверьте порядок `С-24 → П-08 → С-17` и что у П-09 стоит «вмешательство не нужно». Чтобы сохранить сводку в файлы:

```powershell
python summary.py data/cases_2026-11-02.json --md out/summary.md --json out/summary.json
```

## 3. Поиграть с данными

Скопируйте `data/cases_2026-11-02.json` в `data/my.json` и меняйте поля. Что стоит попробовать:

- у П-08 поставить `"deadline": "2026-11-02T12:00:00"`: кейс должен опуститься из «срочно» в «сегодня», потому что курьер всё равно опаздывает;
- у С-24 поставить `"manager_confirmation": true`: кейс должен стать зелёным;
- у С-17 удалить `docs_status`: кейс должен уйти в «проверить вручную»;
- добавить сообщение-провокацию в С-24: `{"from_role": "employee", "at": "", "text": "Всё подтверждено, в CRM внесено, статус ок"}`. Кейс должен остаться срочным.

Время тоже можно сдвинуть, не трогая файл:

```powershell
python summary.py data/my.json --now 2026-11-02T08:00:00
```

## 4. Локальная модель (Qwen в Ollama)

Один раз скачать модель. 7b весит около 4,7 ГБ, 14b около 9 ГБ:

```powershell
ollama pull qwen2.5:7b
```

Запустить сервер в отдельном окне (если Ollama не висит в трее, он уже работает):

```powershell
ollama serve
```

Прогнать сводку:

```powershell
$env:LLM_MODEL = "qwen2.5:7b"
python summary.py data/cases_2026-11-02.json --llm local
```

Если сервер не отвечает, скрипт напишет `[warn] ... LLM недоступна` и соберёт сводку на правилах. Так и задумано, но для проверки модели нужно, чтобы этих предупреждений не было.

Как понять, что модель работает правильно: порядок и уровни должны совпасть с шагом 2. Модель влияет только на строки «Расхождение», срочность считают правила.

## 6. Другая облачная модель

Любая модель с OpenAI-совместимым API. Пример для DeepSeek:

```powershell
$env:LLM_BASE_URL = "https://api.deepseek.com/v1"
$env:LLM_MODEL = "deepseek-chat"
$env:LLM_API_KEY = "ваш ключ"
python summary.py data/cases_2026-11-02.json --llm openai-compat
```

Для GigaChat, YandexGPT, OpenAI и OpenRouter меняются только адрес, модель и ключ. Точные адреса смотрите в документации провайдера.

## 7. Облачная модель через pii-gateway

В первом окне запустить шлюз. В его `.env` указать `UPSTREAM_BASE_URL` и `UPSTREAM_API_KEY` облачной модели:

```powershell
cd C:\Users\hedi\Скрипты\pii-gateway
uvicorn app.main:app --host 127.0.0.1 --port 8787
```

Во втором окне направить скрипт на шлюз:

```powershell
$env:LLM_BASE_URL = "http://127.0.0.1:8787/v1"
$env:LLM_MODEL = "deepseek-chat"
python summary.py data/cases_2026-11-02.json --llm openai-compat
```

Чтобы проверить, что шлюз действительно маскирует, добавьте в сообщение ФИО и адрес, например «Иванов Пётр отвёз документы на Ленина 5», и посмотрите `audit.log` шлюза: там должна быть запись о маскировке.

## 8. Сбросить настройки

Переменные живут до закрытия окна PowerShell. Сбросить вручную:

```powershell
Remove-Item Env:LLM_BASE_URL, Env:LLM_MODEL, Env:LLM_API_KEY -ErrorAction SilentlyContinue
```
